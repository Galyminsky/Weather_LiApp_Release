# Постоянные инструкции проекта

## Gradle и сборка

1. Для Gradle Wrapper используй пользовательский Gradle-кэш: `GRADLE_USER_HOME=%USERPROFILE%\.gradle`.
2. Сборку и тесты запускай в обычном Windows-окружении вне ограниченного sandbox: sandbox может блокировать сетевые подключения к Gradle-репозиториям.
3. Проверенная последовательность команд в PowerShell:

   ```powershell
   $env:GRADLE_USER_HOME = "$env:USERPROFILE\.gradle"
   .\gradlew.bat testDebugUnitTest assembleDebug
   ```

4. Не повторяй диагностику сети и не запускай сборку в заведомо ограниченном окружении, если уже известно, что оно блокирует подключения.
5. Если обычное Windows-окружение недоступно, сообщи об этом и предложи выполнить сборку через Android Studio. Не трать время на заведомо бесполезные повторные попытки.
6. Перед изменениями проверяй состояние проекта и учитывай результаты уже выполненных сборок. Не меняй конфигурацию только ради обхода ограничений окружения.
7. После каждого значимого этапа обновления запускай сборку и соответствующие тесты в проверенном окружении.

Не выполняй commit или push без отдельного запроса пользователя. Не выводи секреты и API-ключи.
